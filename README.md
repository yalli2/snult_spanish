# SNULT 스페인어 인터랙티브 학습 사이트

국제학교 스페인어 **SNULT 시험대비 수업**에서 학생들과 함께 쓰는 인터랙티브 학습 사이트입니다.

🔗 **https://yalli2.github.io/snult_spanish/**

## 구성

| | Part I | Part II | Part III | Part IV |
|---|---|---|---|---|
| **청해** (50) | 1~15 응답 고르기 | 16~30 대화 응답 | 31~40 대화 듣고 질문 | 41~50 글 듣고 질문 |
| **독해** (50) | 1~10 문법·어법 | 11~20 어휘 | 21~35 글 빈칸 | 36~50 독해 |

SET 1 · SET 2 두 세트, **총 200문항**.

## 기능

- **원어민 발음 듣기** — Web Speech API로 스페인어 음성을 자동 선별(es-ES 우선, 고품질 음성 가점). 남녀 화자 구분, 속도 0.75×~1.1× 조절, 문장별·전체 재생.
- **청해 스크립트 가리기** — 실제 시험처럼 음성만 듣고 풀다가, 답을 고르면 스크립트가 자동으로 열립니다.
- **즉시 채점** — 답을 고르면 바로 정답·해설·번역·어휘·문법 팁이 열립니다.
- **Part별 점수 저장** — 브라우저에 저장되어 목차에 표시됩니다. 틀린 문제만 다시 풀기 가능.

## 수업 활용 팁

1. 음성 선택창에서 가장 자연스러운 음성을 먼저 고릅니다(Chrome의 *Google español* 권장).
2. 청해는 `스크립트 모두 가리기` 상태로 두고 ▶ 듣기만으로 진행합니다.
3. 채점 후 **틀린 문제만 다시** 버튼으로 복습합니다.
